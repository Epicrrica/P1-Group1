GLOSSARY:
requirements.txt - Required for installing all required modules for running the project. Before exporting packages/modules to  'main' branch, in your terminal, input "pip freeze >requirements.txt". This will save all installed packages into requirements.txt file. When importing, input "pip install -r requirements.txt" to verify/install new packages/modules.

package.json - Functions like requirements.txt but for javascript packages. Before exporting packages/modules to 'main' branch, in your terminal, input "npm install". When importing, input "npm install --save" to verify/install new packages/modules.
